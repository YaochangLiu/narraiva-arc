# Examples

`package_baseline.py` is a smoke example for NAR-30. It proves a local editable installation can
import the public package. Story-generation examples will be added only after Arc Engine behavior
is migrated and tested under NAR-32.

`story_brief.py` demonstrates the NAR-31 Story Brief v1 contract. It combines Creative Input,
inferred values, and explicit constraints, then prints the privacy-safe System Understanding.
