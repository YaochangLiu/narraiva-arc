# Security policy

Narraiva Arc is pre-Alpha and has no supported release yet. Security fixes target the active
development branch until versioned release support is announced.

Do not disclose a vulnerability in a public issue. Use GitHub's private vulnerability reporting
for this repository when available, or contact the repository owner privately through the GitHub
account. Include the affected revision, reproduction steps, impact, and any suggested mitigation.
You should receive an acknowledgement within seven days.

Never attach real API keys, environment files, user manuscripts, generated private content, or
production logs to a report. Replace them with synthetic values. A local checkout must not retain
provider secrets or user content in tracked files.
